1. Де живе змінна?

Пам’ять комп’ютера — це послідовність байтів, кожен має свій номер: адресу. Коли ти пишеш int a = 5;, компілятор відводить для a 4 байти й запам’ятовує, з якої адреси вони починаються.

Торкнись комірки, щоб побачити її адресу:

Обери змінну.
int a = 5;
cout << a;   // 5       — значення
cout << &a;  // 0x1000  — адреса (оператор &)

Оператор & перед змінною повертає її адресу. Справжні адреси інші й змінюються між запусками — тут вони спрощені.

2. Вказівник — змінна для адреси

Вказівник — змінна, яка зберігає не число, а адресу іншої змінної. Оператор * «переходить за адресою» й дає доступ до значення там.

int a = 5, b = 8;
int* p = nullptr;  // нікуди не вказує
p = &a;            // p зберігає адресу a
*p = 20;           // змінює a через p

Експеримент: виконуй команди й дивись на пам’ять.

Спробуй *p += 1; одразу, поки p не вказує ні на що.

Запам’ятай: &x — «адреса x»; *p — «значення за адресою в p». Розіменування nullptr — помилка виконання.

3. Передача параметрів: значення чи вказівник

За замовчуванням функція отримує копії аргументів. Щоб змінити змінну викликача, передаємо її адресу і працюємо через *. Перевір на задачі swap (обмін значень a і b).

Задача 1. Подвоєння

Напиши void twice(int* p), яка подвоює значення змінної. Виклик: int k = 4; twice(&k); → k == 8.


void twice(int* p) {
    *p = *p * 2;
}


Задача 2. Мінімум і максимум

Напиши void minmax(int x, int y, int* mn, int* mx), яка записує менше число в *mn, більше — в *mx. Виклик: minmax(7, 3, &lo, &hi);


void minmax(int x, int y, int* mn, int* mx) {
    if (x < y) { *mn = x; *mx = y; }
    else       { *mn = y; *mx = x; }
}


Задача 3. Що виведе програма?

int x = 1, y = 2;
int* p = &x;
int* q = &y;
*p = *q + 5;
q = p;
*q = *q * 2;
cout << x << " " << y;


Спробуй намалювати комірки на папері, потім відкрий відповідь.


Відповідь: 14 2. Спочатку x = 2 + 5 = 7. Потім q вказує на x, тож *q * 2 дає x = 14; y не змінювалась.


Підсумок. &x — адреса; int* p — змінна для адреси; *p — доступ до значення; параметр-вказівник дозволяє функції змінити змінну викликача.
